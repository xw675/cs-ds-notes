## 🎯 Learning Outcomes
- **W0** ➔ 
	- map a qualitative claim to the line item it changes
	- name the three sources of edge and why analytical edge suits a student
	- separate shortlisting ratios (price-based) from evaluating ratios
	- compute $\text{ROIC}$ and judge growth against the cost of capital
	- decompose $\text{ROE}$ into margin × turnover × leverage
	- compute $\text{FCF} = \text{CFO} - \text{Capex}$ and argue when negative FCF is acceptable
- **W1** ➔ 
	- distinguish business description from business model
	- analyse segments, geography and value-chain position
	- build an industry overview (definition, headwinds/tailwinds, key players)
	- select a peer set and apply the moat test (uniqueness, relative advantage, durability)
	- write a 5–6 bullet thesis with mispricing, catalyst and falsifier
	- lay out a report to the CFA section list and mark weights
- **W2** ➔ 
	- apply model conventions (hardcode / input / formula / link, check row)
	- link P&L, BS and CF with PPE, RE and cash corkscrews
	- forecast revenue as volume × price and costs by driver
	- build existing-asset and vintage depreciation schedules
	- forecast receivables/payables from days and sign the cash impact
	- run a debt corkscrew with interest and capped repayments
	- normalise to Core EBITDA / Core PAT
- **W3** ➔ 
	- build $\text{FCFF}$, discount at WACC, bridge EV to equity
	- compute $K_e$ by CAPM and WACC with the debt tax shield
	- set terminal value by Gordon growth or exit multiple and sanity-check $g$
	- value by peer multiples with matching numerator/denominator
	- run WACC × $g$ sensitivity and bull/base/bear scenarios; state the call-flipping break-even
	- write a risk matrix with impact and mitigation
